# 魔法戦争 v4 — Mahou Sensou Roguelike

魔法だけで戦うローグライク。森（ファンタジー）→ 街（現代）→ 星（未来）→ 虚無（最終）の 4 つの世界を、部屋を選びながら進みます。
**ひとりでも、ルームコードで最大 4 人の協力でも**遊べます。ブラウザだけで動き、**全画面**にも、**アプリとしてインストール（PWA）**もできます。

## 遊び方

| 操作 | キーボード / マウス | スマホ・タブレット |
| --- | --- | --- |
| 移動 | WASD / 矢印 | 左のスティック |
| 狙う・魔弾 | マウス・左クリック（手動詠唱のとき） | 自動 |
| 回避（無敵） | Space / 右クリック | 「回避」 |
| 魔法 | 1〜6（自動詠唱なら勝手に撃つ） | 下の魔法ボタン |
| 自動詠唱 ON/OFF | T | 右上のボタン |
| 商人と話す | E | 「調べる」 |
| チャット（マルチ） | Enter | — |
| 全画面 / 音 / 一時停止 | F / M / Esc | 右上 |

- 部屋の敵を全滅させると扉が開き、**次の部屋を 2〜3 つから選べます**（戦い・精鋭・宝物庫・泉・商人…扉の上に報酬が出ます）。
- 6 部屋ごとに**ボス**：喰花の女王 / 解体重機キメラ / 銀河鯨 / 名無しの王。4 体を倒すと「深淵」へ続き、周回ごとに敵が強くなります。
- 経験値は仲間と共有。レベルアップで**新しい魔法を覚えるか、持っている魔法を育てる**カードを選びます（魔法は最大 6 つ）。
- 倒れても、仲間がそばに 2.5 秒立てば起き上がれます。全員倒れると終わり。集めた**魔石**は残り、タイトルの「魔石の祭壇」で永続強化に使えます。

## 魔法（50 種 × 4 段階 = 200 の形）

すべての魔法は Lv1〜10 まで育ち、Lv で形も名前も変わります：**初級（Lv1-2）→ 中級（Lv3-5）→ 上級（Lv6-9）→ アルティメット（Lv10）**。

| ファンタジー 20 | 熾火（焔獄の檻）・霧氷（氷河の行進）・紫電（天穿つ雷柱）・曙光（黎明の剣）・影縫い（月蝕）・蔦（千年樹海）・泡沫（深海の圧）・星屑（銀河落とし）・癒し（女神の息吹）・疾風（天嵐）・砂塵（砂漠の王墓）・鏡（鏡界）・狐火（九尾の狐火）・龍（龍王顕現）・魔歌（終焉の交響曲）・呪詛（百呪の宴）・血の魔法（血の契約）・刻（時の静寂）・岩（大陸崩し）・剣舞（万剣の墓標） |
| 現代 15 | リボルバー（弾幕の雨）・狙撃（一撃必殺）・爆弾（クラスター爆撃）・火炎放射（焼夷の海）・ミサイル（戦術核）・煙幕（閃光弾の嵐）・地雷（爆薬の輪）・電撃銃（送電塔）・大砲（艦砲射撃）・放水（消防ヘリ）・警察犬（群狼部隊）・丸鋸（処刑機械）・突撃（暴走トラック）・救急（野戦病院）・空爆要請（飽和攻撃） |

アルティメットを撃つとカットインが入ります。跳ね返る弾、分裂する弾、相棒の犬、砲台、回復の泉、透明化など、魔法ごとに違う動きをします。

ほかに秘宝 24 種、永続強化 6 種、難易度 4 段階（やさしい / ふつう / むずかしい / 魔王）。

## オンライン協力（2〜4 人・ルームコード）

「パトロール」と同じつなぎ方です（PeerJS でブラウザ同士を直接つなぐ。サーバーを用意する必要はありません）。

1. ホスト：名前を入れて「ルームを作る」→ 5 文字のコードが出る
2. 仲間：**同じページ（同じ URL）**を開いて、コードを入れて「参加する」（「招待リンク」を送れば入力も不要）
3. そろったらホストが「冒険を始める」。ロビーとゲーム中はチャットできます

- PeerJS の標準設定（中継サーバー TURN 入り）を使うので、スマホの回線どうしや、ちがう家の Wi-Fi どうしでもつながります。
- ゲームは **GitHub Pages などの https の URL** から開いてください（ファイルを直接開くとオンラインは動きません）。
- 戦いの計算はホストの端末で行います。ホストが抜けると部屋も終わります。12 秒つながらない仲間は自動で抜けた扱いになります。

## 全画面・インストール

- 「全画面」ボタンか F キー。スマホでは横向きに固定します。
- Chrome / Edge / Android：タイトルの「インストール」ボタン（またはアドレスバーのインストール）。
- iPhone / iPad：Safari の共有ボタン →「ホーム画面に追加」。
- インストール後はオフラインでもソロで遊べます（`sw.js` がファイルを持っておきます）。

## 技術

- **スプライトスタッキング**（`js/stack.js`・`js/models.js`）：Sprite Stack Lab の仕組みを移植。キャラ・オリジナルの魔物 20 体とボス 4 体・置き物・壁など約 60 のモデルを、コードで組んだボクセルから輪切りにして重ね、32 方向ぶん光（左上の太陽＋青い補助光）を焼いて描きます。3D モデルは使っていません。
- **pixelfx**（`pixelfx/`）：魔法・爆発・状態異常などのエフェクト。さらにこのゲームのために新しく作りました（`pixelfx/src/fx/mahou/`）：音符の波紋（魔歌）、時計盤、神剣、剣の雨、衛星軌道砲、桜嵐、ナノ群体、炎の陣。
- 音はすべて WebAudio でその場で合成（効果音と世界ごとの BGM）。
- `js/sim.js` はゲームの計算だけ（描画しない）で、ソロとホストで同じものが動きます。

## 手元で動かす

```bash
npx serve .
# または
python3 -m http.server 8080
```

ブラウザで開くだけです（ビルド不要）。GitHub Pages で公開すれば、そのまま URL で遊べます（Settings → Pages → Branch を選ぶ）。

```bash
node tests/sim.mjs      # ボットで全魔法・全段階・全ボスを通す（例外が出ないか）
node tests/fxkeys.mjs   # エフェクト名の抜けを確認
node tools/gen-sw.mjs   # ファイルを変えたら sw.js を作り直す
```
