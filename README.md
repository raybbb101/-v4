# 魔法戦争 v4 — Mahou Sensou Roguelike

魔法だけで戦うローグライク。森（ファンタジー）→ 街（現代）→ 星（未来）→ 虚無（最終）の 4 つの世界を、部屋を選びながら進みます。
**ひとりでも、ルームコードで最大 4 人の協力でも**遊べます。ブラウザだけで動き、**全画面**にも、**アプリとしてインストール（PWA）**もできます。

## 遊び方

| 操作 | キーボード / マウス | スマホ・タブレット |
| --- | --- | --- |
| 移動 | WASD / 矢印 | 左のスティック |
| 狙う・魔弾 | マウス・左クリック（手動詠唱のとき） | 自動 |
| 回避（無敵） | Space / 右クリック | 「回避」 |
| 魔法 | 1〜6（自動詠唱なら勝手に撃つ） | 下の魔法ボタン |
| 自動詠唱 ON/OFF | T | 右上のボタン |
| 商人と話す | E | 「調べる」 |
| チャット（マルチ） | Enter | — |
| 全画面 / 音 / 一時停止 | F / M / Esc | 右上 |

- 部屋の敵を全滅させると扉が開き、**次の部屋を 2〜3 つから選べます**（戦い・精鋭・宝物庫・泉・商人…扉の上に報酬が出ます）。
- 6 部屋ごとに**ボス**：古樹の守護者 / 鋼鉄の重戦車 / 星喰いの機神 / 虚無の魔王。4 体を倒すと「深淵」へ続き、周回ごとに敵が強くなります。
- 経験値は仲間と共有。レベルアップで**新しい魔法を覚えるか、持っている魔法を育てる**カードを選びます（魔法は最大 6 つ）。
- 倒れても、仲間がそばに 2.5 秒立てば起き上がれます。全員倒れると終わり。集めた**魔石**は残り、タイトルの「魔石の祭壇」で永続強化に使えます。

## 魔法（35 種 × 4 段階 = 140 の形）

すべての魔法は Lv1〜10 まで育ち、Lv で形も名前も変わります：**初級（Lv1-2）→ 中級（Lv3-5）→ 上級（Lv6-9）→ アルティメット（Lv10）**。

- **ファンタジー**：火炎・氷結・雷鳴・聖光・闇・大樹・水流・秘術・癒し・炎環・魂喰い・時の魔法・大地・疾風・霊剣・光弓
- **現代**：銃撃・爆弾・火炎放射・ミサイル（極：戦略核）・煙幕・地雷・電撃銃・大砲・放水
- **未来**：レーザー（極：衛星軌道砲）・プラズマ・ドローン・EMP・力場・回転刃・ワープ・重力・ホログラム・ナノ

アルティメットには専用の演出（カットイン）があります。特に次の 8 つは、以前作った Pixel 魔法をもとにした大技です：
**紅蓮の抱擁（Crimson Wrap）/ 絶対零度（Absolute Zero）/ 氷炎反転（Frost to Inferno）/ 世界樹ユグドラシル（Yggdrasil）/ オーバードライブ（Overdrive）/ 特異点ノヴァ（Singularity Nova）/ 妖精の潮（Fairy Tide）/ 射日・九陽落とし（Hou Yi Shoots Down the Suns）**

ほかに秘宝 24 種、永続強化 6 種、難易度 4 段階（やさしい / ふつう / むずかしい / 魔王）。

## マルチプレイ（ルームコード）

1. ホストが「ルームを作る」→ 5 文字の**ルームコード**が出ます（「招待リンク」でも送れます）
2. 仲間は同じページを開いて、コードを入れて「参加する」
3. そろったらホストが「冒険を始める」。ロビーとゲーム中はチャットができます

PeerJS（WebRTC）でブラウザ同士を直接つなぐので、サーバーは要りません。戦いの計算はホストのブラウザで行い、仲間には 20 回/秒で結果を送ります。

## 全画面・インストール

- 「全画面」ボタンか F キー。スマホでは横向きに固定します。
- Chrome / Edge / Android：タイトルの「インストール」ボタン（またはアドレスバーのインストール）。
- iPhone / iPad：Safari の共有ボタン →「ホーム画面に追加」。
- インストール後はオフラインでもソロで遊べます（`sw.js` がファイルを持っておきます）。

## 技術

- **スプライトスタッキング**（`js/stack.js`・`js/models.js`）：Sprite Stack Lab の仕組みを移植。キャラ・敵・ボス・置き物・壁など約 60 のモデルを、コードで組んだボクセルから輪切りにして重ね、32 方向ぶん光（左上の太陽＋青い補助光）を焼いて描きます。3D モデルは使っていません。
- **pixelfx**（`pixelfx/`）：魔法・爆発・状態異常などのエフェクト。さらにこのゲームのために新しく 10 個作りました（`pixelfx/src/fx/mahou/`）：太陽（射日）、紅蓮の抱擁、妖精の潮、時計盤、神剣、天弓の矢の雨、衛星軌道砲、桜嵐、ナノ群体、炎の陣。
- 音はすべて WebAudio でその場で合成（効果音と世界ごとの BGM）。
- `js/sim.js` はゲームの計算だけ（描画しない）で、ソロとホストで同じものが動きます。

## 手元で動かす

```bash
npx serve .
# または
python3 -m http.server 8080
```

ブラウザで開くだけです（ビルド不要）。GitHub Pages で公開すれば、そのまま URL で遊べます（Settings → Pages → Branch を選ぶ）。

```bash
node tests/sim.mjs      # ボットで全魔法・全段階・全ボスを通す（例外が出ないか）
node tests/fxkeys.mjs   # エフェクト名の抜けを確認
node tools/gen-sw.mjs   # ファイルを変えたら sw.js を作り直す
```
